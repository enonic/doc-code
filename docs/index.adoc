== Audience

This reference is for developers building applications that extend or customize Enonic XP or Content Studio. It covers the application framework and development tools, with related topics documented separately:

* https://developer.enonic.com/docs/cms[CMS docs] for content modeling and content APIs
* https://developer.enonic.com/docs/content-studio[Content Studio docs] for the content authoring interface
* https://developer.enonic.com/docs/platform[XP platform docs] for platform architecture and administration

== Introduction

The *Enonic application framework*, also called the *Enonic framework*, is the server-side application framework built into Enonic XP. It provides the programming model and APIs for applications written in JavaScript or TypeScript, including <<web#, web services>>, <<background/tasks#, background tasks>>, <<background/scheduler#, scheduled jobs>>, <<runtime/events#, event processing>>, and access to platform services such as storage and identity.

Functionality is delivered through <<apps#, Enonic apps>> — deployable packages containing code, schemas, assets, or any combination of these. An app can provide content schemas without executable code, or implement APIs, admin tools, websites, and background tasks.

The <<runtime#, XP runtime>> hosts multiple apps side by side and executes any JavaScript modules they contain. TypeScript is compiled to JavaScript before deployment.

== Where to start

<<tooling#, Tooling>>:: The CLI, sandboxes, starters, build system, and CI/CD setup for developing and deploying apps.

<<apps#, Applications>>:: Application packaging, namespaces, lifecycle, and configuration.

<<runtime#, Runtime>>:: The execution model, module system, threading, and cluster behavior.

<<web#, Web>>:: HTTP APIs, admin tools and extensions, sites, and webapps, with shared request handling, authentication, WebSockets, and SSE.

<<background#, Background>>:: Tasks and scheduled jobs for asynchronous work.

<<libraries#, Libraries>>:: The standard APIs for content, storage, identity, mail, and other platform services.
